# Real-agent workflow acceptance runs

Executed on 2026-10-16 by three isolated Codex sub-agents against disposable synthetic product directories. These are execution records, not claims of installation compatibility with other hosts or evidence of marketing effectiveness. No content was published.

The agents performed filesystem actions and produced drafts, review records, checkpoints and logs. Author/Cop roles inside a scenario used the documented sequential fallback where noted; the artifact agent also tested the isolated Cop input boundary. User decisions needed for state transitions were explicit synthetic test inputs, not real product approvals.

## Findings and repairs

- A saved choose cursor could bypass missing objections and a missing verdict. Resume now validates prerequisites. The identical seven-objection fixture resumed debate, added only two missing pairs and the verdict, and preserved prior outputs byte for byte.
- Current HN guidelines prohibit generated post text and AI-edited comments. An early authorship check now produces a blocked internal planning handoff. A usable hosted demo can satisfy the no-repository eligibility question without making generated copy acceptable.
- New same-slug work and explicit resumption worked, but a slug-only request was ambiguous. Artifact rules now ask before writing and treat an orphan companion review as an occupied path. Both probes passed after the clarification.
- Canon's manifesto-only question rule conflicted with piece format questions. Its scope is now explicit. The same conflicting-format request again asked the necessary question without any file mutation.

The parent inspected saved outputs, recalculated text lengths, compared original/recovered files, and added archive-evidence assertions alongside instruction-contract regressions. All nine acceptance scenario groups were exercised; blocked source/evidence cases are expected results, not ready drafts. Historical fixtures remain historical.

## Validation boundary

This is a single Codex-host run with synthetic products and explicit test choices. Filesystem skill loading stood in for installation and native Skill dispatch. Nested author/Cop roles mostly used sequential fallback, not independently spawned roles. The critic missing-input probes were executed by a separate scenario agent given explicit input packs. No cross-host installation, repeated-model reliability, real audience effectiveness, concurrent writes or production publication was tested. Retained Python scripts record the agent-authored text and actual filesystem operations; replaying those scripts alone does not rerun a model.
