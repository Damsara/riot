## Format question

Ask which platform: X, LinkedIn, Bluesky, or Threads.

## X

| Rule | Value | Source |
|---|---|---|
| Character limit | 280 on the free tier; Premium extends to 25,000 but only the first 280 show before "Show more" | https://help.x.com/en/using-x/x-premium |
| Link handling | Contested: X's owner denies any explicit link penalty, but an independent 2026 analysis found links cut reach for publishers by roughly 30 to 90% depending on the study; X began testing softer link handling in October 2025 | https://x.com/elonmusk/status/1915806794393457034, https://www.niemanlab.org/2026/04/do-links-hurt-news-publishers-on-twitter-our-analysis-suggests-yes/ |
| Hashtags | X's owner has told users to stop using them, stating the system no longer needs them | https://x.com/elonmusk/status/1869070358210572306 |

## LinkedIn

| Rule | Value | Source |
|---|---|---|
| Character limit | 3,000 characters; roughly the first 200 to 210 show before "see more", exact figure unverified but widely reported | https://www.linkedin.com/help/linkedin/answer/a528176 |
| Link handling | Dwell time outranks fast reactions like likes as an official ranking signal; a link in the post, or in its first comment, reportedly cuts reach 60 to 68%, a third-party estimate, unverified | https://www.digitalapplied.com/blog/linkedin-algorithm-2026-engagement-strategy-guide |
| Hashtags | Hashtag-following was removed, so they act as SEO keywords rather than a reach lever; 1 to 3 per post is the common guidance, unverified | https://www.digitalapplied.com/blog/linkedin-algorithm-2026-engagement-strategy-guide |

## Threads

| Rule | Value | Source |
|---|---|---|
| Character limit | 500 for a standard post; a text attachment extends it to 10,000 characters | https://help.instagram.com/788669719351544/ |
| Link handling | Meta states the algorithm does not downrank links but places little value on link clicks; Meta has separately said link performance has since improved | https://www.socialmediatoday.com/news/meta-says-link-posts-ranked-properly-threads-reach/750126/ |
| Hashtags | No `#` tags. One clickable topic tag per post, by design, to keep tags about community rather than reach | https://searchengineland.com/threads-hashtags-topic-tags-435595 |

## What gets you punished

- Engagement bait (asking for likes, replies, or shares as a substitute for content) is a named, separately enforced policy on all four platforms.
- Bought or coordinated engagement, follower farms, reply rings, sock puppets, is banned by name on X, LinkedIn, and Bluesky.
- On X, soliciting replies as a growth tactic three or more times pulls an account from the creator revenue-share program.
- On Threads, hashtags carried over from an Instagram cross-post get stripped rather than shown.

## Draft rules

1. The hook is the first line; nothing before it earns the platform's fold.
2. One idea per post. A second idea is a second post.
3. End on the opinion, not a call to action, unless the occasion is a launch.
